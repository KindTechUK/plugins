# uk-nonprofit

UK charity practice for an AI assistant: regulation, fundraising and reporting know-how,
written for people who run and fund charities. This plugin holds skills only. It needs
nothing hosted and no connector, so it works in any assistant that reads skills.

No skill has been published here yet, so the plugin is not listed in the marketplace.
To propose one, read the [guide at the top of the repository](../../AGENTS.md).
