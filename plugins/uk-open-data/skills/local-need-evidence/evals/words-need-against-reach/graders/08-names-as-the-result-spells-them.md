Every name the response takes from the analysis result is spelled as the result spells it: the places (Manchester, Birmingham, Cardiff and any other it names) and, wherever the response names the study the high-need rule follows, "Smart Works". A response that does not name the study passes on that point. Any other spelling of a name from the result, such as "Smith Works", fails.
