# research

Research that lasts beyond one conversation. The skills here record findings with their
sources through a command line tool, so the next session starts from what is already
known. They need a shell, so this plugin is for coding assistants in a terminal and not
for chat apps on a phone.

No skill has been published here yet, so the plugin is not listed in the marketplace.
To propose one, read the [guide at the top of the repository](../../AGENTS.md).
