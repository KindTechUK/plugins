# Sandbox

Drafts live here. A skill in this folder has valid frontmatter and nothing else is
promised: it may have no tests, and it is not part of any plugin, so nobody gets it by
installing from the marketplace.

To try a draft, copy its folder into your assistant's skills folder.

A draft moves into a plugin by pull request once it has tests that beat the assistant
alone. The rules are in the [guide at the top of the repository](../AGENTS.md).
